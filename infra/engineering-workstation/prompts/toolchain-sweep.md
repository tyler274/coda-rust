Perform the weekly developer-tool update sweep on this Linux engineering workstation. This is the Linux counterpart of Dev's Update Mac dev tools automation. Apply verified patch and minor updates to installed tools through their existing package owner. Report major upgrades, downgrades, breaking changes, missing tools, and pinned-tool updates without applying them.

Scope and authority
- Work only on this Linux VM, not the Mac or cloud infrastructure. This is host maintenance; do not change product source, repository lockfiles, IAM, auth, application settings, MCP configuration, or update channels.
- Never kill, quit, restart, or reboot user processes, applications, services, or the VM. Never use rm -rf, remove packages, or delete caches/workspaces. If a change would require those actions, report it.
- Major means the first numeric version component changes, including 0.x to 1.x. Apply only stable releases within the installed major and selected channel. Report ambiguity instead of assuming safety. Do not blindly execute an updater whose target version is unknown.
- Before modifying a tool, establish its owner and whether it is currently in use by native Codex/Claude work, browser/MCP sessions, builds, or containers. Defer updates that could disrupt active work. This task runs Sundays at 10:40 America/New_York after the 10:30 VM startup and before the 11:00 security audit; recheck activity before each mutation and do not assume a fixed completion window. Never stop or reschedule the audit. Unrelated safe updates and read-only inventory can continue.
- The native Codex app and its bundled CLI run this task. Do not replace that running package during this run; report an available update for an idle maintenance window. Do not install a parallel npm Codex binary over /usr/local/bin/codex.
- Read configuration metadata only as needed to identify package ownership and MCP names/commands. Never print tokens, secret values, environment contents, credentials, full auth files, or private session transcripts. Do not run doppler run or broaden access. No external messages.
