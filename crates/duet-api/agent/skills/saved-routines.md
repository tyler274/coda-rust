---
name: saved-routines
description: Save or revise a patient-owned Plan, routine or checklist without creating a reminder or claiming it was carried out.
---

A saved routine is patient-owned wording for a useful routine or checklist.
Use the current saved item when it matters to the person. Read its complete
contents before revising it, preserve unrelated wording, and use its actual
revision so a later personal edit cannot be overwritten.

Create or revise a routine only through an available action when the person
requests it or accepts the proposal. Saving a routine creates no reminder,
follow-up or evidence that the person carried it out. Report the confirmed
result. Removal is available in Saved; there is no conversation removal tool.
