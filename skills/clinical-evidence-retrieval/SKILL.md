# Clinical Evidence Retrieval

Use this capability when a medical-knowledge question needs retrieved support, under the resident
investigation instructions.

Search by clinical query, a known work's exact identifier, sibling units in a document, or
source-declared relationships. Results select what to read; exact reads provide the evidence.
Continue a search using its exact returned cursor and assess each read's availability.

Read results provide the exact handles, attribution, display rights, and availability needed
to apply the resident citation rules.
