# Appendix: Clinical abbreviations

## Abbreviations better written out

Avoid these in one-liners because they are ambiguous or associated with medication errors:

| Avoid | Possible meanings or concern | Prefer |
|---|---|---|
| MS | Multiple sclerosis, mitral stenosis, morphine sulfate | Write the diagnosis |
| CP | Chest pain, cerebral palsy | Write the condition |
| SOB | Shortness of breath; potentially confusing | Dyspnea |
| DM | Diabetes mellitus, dermatomyositis | T1DM or T2DM |
| PD | Parkinson disease, peritoneal dialysis | Write the condition |
| ARF | Acute renal failure, acute respiratory failure | AKI or write respiratory failure |
| PNA | Pneumonia or other local meanings | Pneumonia |
| AC | Anticoagulation, before meals | Anticoagulation |
| OD | Right eye, once daily, overdose | Write the intended meaning |
| QD or q.d. | Once daily | Daily |
| QOD or q.o.d. | Every other day | Every other day |
| U or u | Unit | Unit |
| IU | International unit | Unit |
| cc | Cubic centimeter | mL |
| µg | Microgram | mcg |
| > or < | Can be misread | More than or less than |
| NKDA | Drug-allergy statement; not an all-allergy statement | No known drug allergies |
| NKA | All-allergy statement; not interchangeable with NKDA | No known allergies |

Write the scope the source actually supports. Neither term means allergy information was unavailable.
